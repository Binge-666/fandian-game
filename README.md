# 饭点大作战

60 秒内按顾客的热量、预算、口味配餐的小游戏。纯静态，双击 `index.html` 就能玩。

**在线玩**（手机浏览器直接打开，打完可发战书和好友 PK）：

https://binge-666.github.io/fandian-game/

- 1 个主食 + 1 杯饮料，最多 4 件
- 总价不能超预算；口味要匹配
- 热量差越小星级越高，连续 3 星有连击倍数
- 3 颗心，60 秒，结束可复制战绩

## 直接玩

双击 `index.html`，或部署到任意静态托管。

演示时可以用 `index.html?play=1` 跳过开始页，直接进入游戏。正常入口不要带参数。

## 本地预览

不需要 Node，也不需要安装依赖。想用本地服务器：

```powershell
npx serve .
# 或
python -m http.server 8080
```

然后打开 `http://localhost:8080`。

## 规则与计分

```text
3 星：热量差 <= 30
2 星：热量差 <= 80
1 星：热量差 <= 150
失败：超预算 / 口味错 / 热量差 > 150 / 耐心耗尽（顾客走人）
基础分 = max(20, 100 - 热量差 * 0.6)
3 星加成 +60，2 星 +30
斤两不差：热量差 <= 10 时 +50
手速加成：出餐时顾客耐心 >= 60% 时 +30
耐心：每单 18 / 15 / 12 秒，随局内进度收紧
连续 3 星：第 1 次 x1，第 2 次 x2，第 3 次起 x3
本单得分 = round((基础分 + 星级加成) × 连击倍数) + 斤两不差 + 手速加成
```

订单由「主食 + 饮料 + 可选小食/甜品」组合生成，保证每单有解。

## 部署

腾讯云 EdgeOne Pages（国内访问快）：EdgeOne Pages 控制台 → 创建项目 → 直接上传/拖放本目录 → 得到 `https://xxx.edgeone.app` 链接。

GitHub Pages：新建独立仓库，把本目录文件推到 `main`，Settings → Pages → Deploy from a branch → `/ (root)`。

或 Netlify / Vercel 直接拖拽本目录，不需要构建命令。

注意：`index.html` 里静态资源带 `?v=20261024` 版本号，更新素材或代码后记得同步升版本号，避免老用户拿到缓存。
